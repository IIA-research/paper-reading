Unlike traditional agent benchmarks, which hand over a specific task, this work focuses on proactive agents: the agent should discover what work it ought to do by itself, rather than waiting for user input.

Evaluation has two parts: whether the agent found the right work, and whether it then did it correctly.

All data is simulated: a company with people and an org structure, plus events, rendered into a system.

Stopping to ask a human counts as a failure.
